About This Project

This College Library Management System was built to solve a real problem at our university — keeping track of books, students, and issue/return records without relying on messy WhatsApp groups or paper registers.

The core logic (adding books, issuing books, calculating fines, searching records) was first written in C++, using arrays, structs, loops, and conditional statements. This webpage now uses the exact same logic, rewritten in plain JavaScript so it works live in the browser, saved using localStorage. A Java Swing desktop version is also included as an alternative GUI.
